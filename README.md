# 🛒 Flipkart Sales Analysis

An end-to-end data analysis project based on Flipkart sales data, using **Excel, SQL, Python, and Power BI** to clean, analyze, visualize, and derive business insights from the dataset.

---

## 📌 Project Overview

This project focuses on analyzing Flipkart sales data to understand sales performance, customer purchasing behavior, product categories, payment methods, and overall business trends.

The project follows a complete data analytics workflow:

**Data → Cleaning → Analysis → Visualization → Business Insights**

---

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing product categories
- Understand customer purchasing patterns
- Analyze payment method usage
- Identify sales trends over time
- Create an interactive Power BI dashboard
- Perform data analysis using SQL and Python
- Prepare the dataset for business reporting
